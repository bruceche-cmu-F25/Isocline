# Alfred 风格

> **用途**：Alfred 现在长什么样、说话什么口气、东西怎么摆。写新页面、改旧页面之前先看这一份。
>
> **状态**：2026-11-19 整理。这里只收已经定下、并且已经在 App 里的东西；每条后面写了出处。
> - 颜色的来由和参考：[visual-style.md](../research/visual-style.md)（调研报告，第二版）。
> - 形象的来由：[alfred-entity.md](../research/alfred-entity.md)。
> - 布局的来由：[workspace-architecture.md](workspace-architecture.md)。
>
> 标「我的默认」的是做的时候顺手定的，你还没明确点过头。

## 1. 一句话

**纸上的墨水。** 暖白的纸，近黑的字，一个靛蓝的 Alfred。颜色可以多，但每个颜色只有一个意思；页面安静，重点才显得出来。说话短，东西在原地改，Alfred 先动手，你只说「好」或「不」。

你给的几个方向，原话：
- 简约而不简单，有呼吸感，和用户能产生 connection，要一个简单好用的底座；
- 简约大气，可以参考融合优秀的设计；
- 颜色可以多一些，要有重点，明暗适中，不能平。

## 2. 颜色

只有一个文件：`packages/ui/src/tokens.css`。原型里的 `prototype/tokens.css` 是指向它的链接。写样式时只用这些变量，不写死色值。

### 2.1 四类颜色，各有一个意思

| 类 | 变量 | 意思 | 用在哪 |
|---|---|---|---|
| 中性色 | `--bg` `--paper` `--raise` `--wash` `--line-soft` `--line` `--muted` `--copy` `--ink` | 底、线、字 | 几乎所有地方 |
| Alfred 色 | `--alf` `--alf-soft` `--alf-solid` `--on-alf` | Alfred 本人和它做过的事 | 形象、链接、回执、「Alfred 加的 / 改的」、焦点框 |
| 状态色 | `--warm` `--now` `--ok`（也可 `data-k="warm|now"`） | 琥珀 = 等你决定；红 = 现在 / 危险；绿 = 完成 | 等你的数字、今天、现在的时间线、删除、成功的点 |
| 领域色 | `data-k="blue|green|violet|orange|teal|yellow|pink"` | 是什么事：工作、生活、学习、出行、健康、财务、家人朋友 | 日程块、待办圆圈、标签、页面图标 |

规矩：
- **红色和琥珀不当领域色。** 红只表示「现在」和危险，琥珀只表示「等你」。
- **状态色从不单独出现**，总带着文字或数字。琥珀和橙、黄离得不够远，单靠颜色分不清。
- **领域色顺序固定**：蓝、绿、紫、橙、青、黄、粉。新的日历或领域按这个顺序取，第 8 个开始复用。顺序是校验过的：相邻两色对色弱读者也分得开。
- **任意两色放在一起可能接近**（蓝↔紫，绿↔青），所以日程块和标签都写名字，日历上有图例。
- **Alfred 排的日程不改颜色**：保留领域色，加虚线边和一个 Alfred 色的小点。颜色说「是什么事」，虚线说「是谁排的」。

### 2.2 每个颜色四个用法

在元素上写 `data-k="…"`，它就有：

| 变量 | 用法 |
|---|---|
| `--k-solid` | 实色：点、色条、图标、圆圈 |
| `--k-fill` | 浅底：日程块、标签、头像 |
| `--k-text` | 同色文字：放在浅底或页面上 |
| `--k-line` | 描边 |

`data-k="alfred"` 和 `data-k="gray"` 也有这四个，分别用 Alfred 色和中性色。

### 2.3 页面识别色

每一页一个颜色，只用在它的图标上（侧栏、顶栏标题前）。定义在 `shell/pages.tsx` 的 `k`：

| 页 | 颜色 |
|---|---|
| 通知 | 琥珀 `warm` |
| 日程 | 红 `now` |
| 待办 | 蓝 |
| 邮件 | 青 |
| 链接 | 紫 |
| 自动任务 | 绿 |
| 开发 | 紫 |
| 设置 | 灰 |

### 2.4 明暗

- **浅色和深色跟随系统**（`public/scheme.js` 在首帧前设 `data-scheme`）。深色是自己的一套值，不是反相：越往上浮越亮，彩色降饱和。
- **深色的底是柔和的深灰**（OKLCH L 0.20），不是近黑，这样彩色的浅底才有位置。
- **不用纯黑字，不用纯白底。** 文字对比：标题 `--ink` 约 14:1，正文 `--copy` 约 7:1，次要 `--muted` 至少 4.5:1（在侧栏上也是）。
- **暖度按层递减。** 暖色只留在接近白的面上，中间调和文字接近中性；否则「纸」会在中间发米黄、卡其，和靛蓝不搭（你 2026-11-18 指出的）。
- **默认主题是「纸」**。`tokens.css` 里还有「石」「雾」「夜」，领域色和状态色在所有主题里一样。

## 3. 层次

**强调阶梯**，重点靠周围安静，不靠到处加粗加色：

| 级 | 样子 | 例子 |
|---|---|---|
| 0 静 | 灰字，没有颜色 | 时间、元信息、过去的日程、做完的待办 |
| 1 标识 | 色点、彩色图标、彩色圆圈 | 侧栏图标、列表的点、待办圆圈、图例 |
| 2 着色 | 浅底 + 同色字 | 日程块、领域标签、「等你决定」、Alfred 回执 |
| 3 实色 | 实色底 + 白字 | 每个区域**最多一个**：等你的数字、今天的日期、主要按钮 |

两条防「花」的底线：
- 一个区域最多一个实色。
- 除了日程块和标签，彩色只用在点、图标、圆圈这类小面积上。

## 4. 文字

- **字体**：系统字体（`--sans`：苹方 / SF / Segoe / Noto CJK）。时间和数字用等宽 `--mono`。字标（wordmark）用 Geist Serif 正体（`--wordmark`，2026-11-21 定）：它只有一个字重、没有斜体、没有中文，所以只给字标，不进正文。衬线 `--serif`（Georgia / 宋体）留给空状态标题和面板标题。对比见 `prototype/serif.html`。
- **所有字号用 rem**，因为设置 → 通用里可以把字调小、调大（`html[data-text]`）。
- **字号**（16px 为 1rem 时）：

| 用途 | 字号 / 字重 |
|---|---|
| 顶栏页面标题 | 17 / 650 |
| 手机上的页面标题（`.page-head`） | 22 / 650 |
| 正文 | 15 / 400，行高 1.6 |
| 列表里的次要行、顶栏的一句话、chip | 13 |
| 标签、日程标题、数字 | 12 / 500–600 |
| 最小的说明 | 11 |

- **字重只用三档**：400；500–600；650。层次靠字重和颜色，不靠把字号拉得很大。
- **中英文都要放得下。** 英文通常更长，两种语言都要看一遍。

## 5. 图标和标

- **线图标**：20×20 的格子，描边 1.6，圆头圆角，颜色跟文字（`shell/icons.tsx`，样式在 `styles.css` 的 `svg`）。新图标画在同一套格子里，不从图标库拿实心图标。
- **别家的标**（Gmail、Notion、模型厂商…）只出现在那个服务的名字旁边，说明这一行属于谁。来源、许可和清理规则见 `packages/ui/src/brand/README.md`。单色的标不带 `fill`，跟着明暗走。
- **链接页用网站自己的图标**（favicon）。

## 6. 形状、线和阴影

- **少画线**。分区先靠底色的明暗（`--paper` 侧栏、`--bg` 页面、`--raise` 卡片），需要线时用 `--line-soft`，更重一档才用 `--line`。
- **圆角**：小控件 6–8px，卡片和输入 10–14px，弹出卡片 18px，chip 和药丸 999px。
- **阴影只给浮在页面上的东西**：问答条的卡片、菜单、日历的小卡用 `--shadow`；居中的弹出卡片阴影更深一档。页面里的卡片不加阴影。
- **焦点**：2px Alfred 色的框，外移 3px。

## 7. 布局

**整页切换，不拼仪表盘。** 每一页占满一整页：通知、日程、待办、邮件……（你 2026-11-18 定的：四个放一起信息展示不开。）

桌面上，从上到下、从左到右：

1. **顶栏** 52px。
   - 左段和侧栏一样宽，下面那条竖线一直通到侧栏边：Mac 的三个窗口按钮、收侧栏按钮（⌘\）、日常 | 开发两个图标。
   - 右段：页面图标 + 标题 + 这一页的一句话（灰），最右只有一个齿轮。点开是小菜单：外观（浅色 / 深色 / 跟随系统）、语言（中文 / EN），最下面「全部设置 ⌘,」。在设置页时齿轮只是变深，不垫灰块（2026-11-20 定，原型 `prototype/corner.html` 的 A）。
2. **侧栏**：可以整个收起，不留图标栏。只显示当前这一边：日常 = 工作台 + 模块 + 对话；开发 = 开发页和项目会话。
3. **页面**：页面自己的控件在上面。
4. **问答条**：在页面最底下，一行。问 Alfred 和搜索（⌘K）都在这里。它的卡片从下往上展开，盖住的是列表的尾巴，不是正在读的东西。**不要再挪到顶上**：右上角和标题旁边都试过、都放弃了。
5. **Alfred 面板**（右侧）：只给比一行长的往来，可以收起、展开到全宽。开发页保留完整的对话。

手机（窄于 700px）：没有顶栏，页面自己写名字；底栏只有图标，最左是侧栏的抽屉；点底栏的形象，标签栏变成问答条。

### 7.1 任何大小都不许叠字

你的原话：每个地方都要注意字体不能重叠，在任何大小的视图下。

- 页面里的东西按**页面这一栏的宽度**排（`@container page`），不按窗口宽度（`@media`）。Alfred 面板打开时，宽窗口里的页面栏可能很窄。`@media (max-width: 700px)` 只管手机外壳。
- 一行「文字 + 按钮」要有窄的叠放形式；文字格子要 `min-width: 0`，加省略号或 `overflow-wrap: anywhere`。
- 页面栏最少 320px（`shell/layout.ts` 的 `ALF.pageFloor`），不够时侧栏先让。
- 做完要在 320–420px 的页面栏下、中英文各看一遍。

## 8. 交互

- **Alfred 先动手，你只说好或不。** Alfred 准备好的改动是一张提议：通知页上一张卡，要落的地方有一个虚线的影子（日程、待办、邮件下面）。好 / 改 / 不。追问用按钮，不开对话。
- **只有一个地方写字。** 每一页底下那一行。点选一件东西（一封邮件、一条提议）就把它挂到这一行上，说几句话就是改它。不在东西旁边再放一个输入框。（2026-11-19 定：「统一还是好一点」。）待办页的添加行是暂时的例外。
- **东西在原地变。** 结果落在页面上，带撤销；不要回一段话说「已为你添加」。
- **手动看、加、改一件东西：页面中间弹一张卡，背后的页面模糊**（8px 模糊，盖 40% 的页面色，卡片在 `--raise` 上，Esc 或点旁边关掉）。看详情、编辑、删除确认都在同一张卡里换。参照 `Calendar.tsx` 的 `Pop`。不用插在页面里的卡片。
- **Alfred 写东西时看得见它在写**：先出卡片和正在写的线，再逐字打出来（1–2.4 秒，点一下跳过）。

## 9. 动效

- **一条缓动**：`--ease`（cubic-bezier(.23, 1, .32, 1)），快起慢停。
- **时长**：悬停、按下 150–200ms；弹出卡片 160ms；形象和较大的变化 400–600ms。
- **尊重「减少动态效果」**：所有循环和打字动画在 `prefers-reduced-motion` 下停掉，直接给结果。

## 10. 形象

- **超立方体线框**，没有脸，没有眼睛。代码只有一份：`packages/ui/src/entity/tesseract.js`（`@alfred/ui/figure`）。
- 本体（静、打招呼）是超立方体；其他状态是简单一档的立体线框：听 = 球，想 = 八面体，说 = 叠起的圈，做 = 本体慢慢双旋，等你 = 琥珀四面体，完成 = 绿立方体，出错 = 红色交叉梁，睡 = 扁片。
- 远的线淡向底色（深浅），只有菜单栏的单色图标是平的。
- 换状态时旧线收起、新线一笔一笔画出来。
- 本体会动（2026-11-20）：平静时呼吸、偶尔眨眼；做事和想得久时慢慢双旋，同步时翻涌；做完事跳一下，被按到时一缩一晃，第一次出现时从一个点长出来，Mac 上说欢迎时展开成八个立方体的十字，长出来和展开最后都停在板正的样子；待机时还会转一圈、踮脚转、抛起来（2026-11-22）。动画都要连续，不跳帧。见 [alfred-entity.md](../research/alfred-entity.md) §4.4。
- **屏幕上只有一个 Alfred。** 通知由它说出来：形象跳一下，旁边展开一张说话的卡。
- 风格上限：平面单色，但可以是带深浅的立体线框。不要写实 3D、不要渐变光球。
- 避开的形状：对称双瓣（像 Meta）、发光的球（像 ChatGPT）、四角星（像 Gemini）、放射的火花（像 Claude）、任何以圆盘为中心的东西（读起来像眼睛）。

## 11. 文案

- **短。** 状态行、提示、药丸、页面的一句话：说有几件、是什么，几个字就够，句末不加句号。例：「2 件等你决定」「3 封未读」。不说「其余的我已经处理好了」这类安慰和解释。（2026-11-19。只管界面上的短句，不管 Alfred 在对话里怎么说。）
- **中英文都有，所有地方**：界面、Mac 主进程、模块里的文字（授权说明、提议预览）。语言存在主节点上，所有设备跟着它。字典在 `packages/ui/src/i18n/{zh,en}.ts`，以中文为准，有测试检查两边的键一致。
- **Alfred 说「我」，叫你「你」。** 我的默认。

## 12. 不做的

- **作品集风格**（bruceche.com 那一套）：2026-11-18 做过，你说「不好，回退」。
- **仪表盘网格**：页面整页切换。
- **常开的对话面板**放在日常页上：太重，改成底下一行。
- **问答条放在顶上**、右上角浮动按钮：都试过、放弃了。
- **侧栏收成图标栏**：收起就整个不显示。
- **插在页面里的编辑卡片**：用弹出卡片。
- **形象**：Sky、点阵球、火焰、手、领结、字母 A、笑脸，见 [alfred-entity.md](../research/alfred-entity.md)。
- **会话页的「超立方体内部」背景**（星际穿越五维空间那种走廊，像素/抖动/字符三种画法）：2026-11-20 做过，满墙光带太乱，减到只剩框线也不行，你说「放弃」。

## 14. 还没定的

- 品牌字体：字标已定 Geist Serif；标题要不要也用它（只对英文有效）还没定。
- 要不要开放任意自定义颜色（像 Google 日历那样）。
- 高对比主题、P3 广色域。
- 待办页的添加行要不要并进底下那一行。
- 较长的结果（比如回信草稿）落在页面上还是卡片里：邮件已经落在页面上，其他页还没做。
