# 日历上的待办：每天该做的、拖下来的，都在日历上

> 状态：v0.1 草案（2026-11-24），等你看。原型：[prototype/calendar-todos.html](../../prototype/calendar-todos.html)。代码没开始。
> 起因：你 2026-11-24 的原话「每天也没有延期的任务日历上」。我理解成：日历页只画日程，待办一条都不上；没做完、拖下来的待办，日历上也看不到。**如果你说的是别的意思，这份文档整个作废。**
> 依据：`packages/ui/src/Calendar.tsx`（三种视图）、`packages/ui/src/Todos.tsx`（`runsOn`、`TodayProgress`、待办卡片）、`modules/todo/src/types.ts`（待办的日期字段）、[today-and-inbox.md](today-and-inbox.md) §3.1c（排一下今天）。
> 标记：**【事实】** 读代码核实过；**【默认】** 我的默认，等你点头。

## 0. 结论

1. **日历上每天多一行「待办」**，在「全天」那一行下面。这一天截止的、计划这天做的、跨几天正在做的，都在这行里，前面一个圆圈，点一下就勾掉。
2. **拖下来的都落到今天。** 过了日子还没做完的待办，不再留在原来那天，统一出现在今天这一行的最前面，标红，写着「拖了 2 天」。往后翻是干净的，往今天看，欠的一眼就有。
3. **有钟点的待办在时间格里画一道截止线**，不画成一块（待办没有长短）。
4. **只是看和勾，不往 Google 日历写。** 待办还是 Zirma 自己的。要占时间，用「排一下今天」或者在卡片上点「放进日历」。
5. **不加新数据，主节点不改。** 只改界面：日历页多读一份待办的快照，用待办现有的操作（完成、改日期）。

## 1. 现在的样子【事实】

| | 现在 |
| --- | --- |
| 日历页 | 三种视图：今天、周、月。只画 Google 日历的日程，加上等你点头的提议里的日程（虚线） |
| 待办页 | 按天分组，右边一条「今天」栏：今天完成几件、下一个截止、截止前还有多少空档 |
| 「今天」的算法 | 今天截止的、跨几天且今天在里面的、**以及截止日已过还没做完的**，都算今天的（`TodayProgress`）。待办页里拖下来的已经算进今天，日历上没有 |
| 待办的日期 | `due` 截止日；`at` 截止钟点；`startDate` 跨几天时的第一天；`plannedOn` 打算哪天做（不是截止） |
| 从日历来的待办 | 日程可以自动变成待办（`source.kind = "calendar"`），那条待办就是那个日程本身 |

所以问题很具体：同一套「今天该做什么」，待办页算了，日历页没画。看日历排时间的时候，看不到这周哪天堆着截止、今天还欠着几件。

## 2. 哪些待办上日历、上在哪天【默认】

| 待办 | 画在哪 |
| --- | --- |
| 有截止日 `due`，没做完 | 截止那天 |
| 跨几天（`startDate`–`due`） | 一条横跨这几天的条，像跨天的全天日程 |
| 有 `plannedOn`（打算哪天做） | 打算的那天，标「截止 12/2」；截止那天不再画一次 |
| **截止日（或打算的那天）已过，没做完** | **只在今天**，排在最前，红色，「拖了 N 天」。原来那天不留影子 |
| 已经做完 | 做完那天，划掉、变淡。月视图里不画，省地方 |
| 没日期的 | 不上日历（它们在待办页） |
| Zirma 从邮件挑出来、你还没收下的建议 | 不上日历 |
| 从日历日程变来的待办 | 不再画一次（日程本身已经在）。那条待办勾掉了，日程上加一个小勾 |
| 等你点头的提议里要加的待办 | 虚线，和提议里的日程一样 |

**拖下来的为什么只放今天，不在原来那天留影子：** 你要的是「今天还欠着什么」。在过去的日子留一份，往回翻会以为那天还有事，看今天又要数两遍。待办页已经这样算（`TodayProgress`），日历跟它一致。

## 3. 三种视图里长什么样【默认】

**周视图（电脑）**

```
          一 23   二 24(今天)        三 25        四 26
全天      ·       ·                  组会日        ·
待办      ·       ○ 交报销 拖了2天    ○ 实验报告    ○ 复习 14848
                  ○ 回 Leo 拖了1天    ━━━━━━━━━━ 写 final report ━━━━━━━
                  ○ 订机票
09:00 ─────────────────────────────────────────────────────
...
21:00             ┄┄ ○ 交作业 21:00 ┄┄
```

- 「待办」行在「全天」行下面，每天一格，每条一行：圆圈、标题、拖了几天或截止钟点。
- 一天超过 4 条，第 4 条位置写「还有 3 件」，点开那天的列表。
- 有钟点（`at`）的，时间格里在那个钟点画一道虚线，带标题，点它和点「待办」行里那条一样。
- 今天那一格左上角一个数：「4 件，拖了 2」。

**今天视图（手机默认）**：日程列表上面先一段「待办」：拖下来的在最前（红），然后今天截止的、今天打算做的。点圆圈就勾。

**月视图**：每天格子里日程下面，最多 2 条待办（一个小圆点加标题），多了写「+3」。今天的格子里，拖下来的那几件算进去，红点。

**手机周视图**（按天的列表）：每天先列日程，再列待办。

## 4. 点了会怎样【默认】

- **点圆圈**：勾掉（`todo.complete`）。这条在原地变淡、划掉，留 2 秒，可以撤销。
- **点标题**：弹出和待办页**同一张**卡片，页面在后面变模糊（和日程卡片一样）。卡片上能改截止日：「今天」「明天」「下周一」三个快捷，或者选日子（`todo.update`）。还能「打开待办页」。
- **改了日子**：这条挪到那一天。拖下来的挪到明天，就不红了。
- **「放进日历」**：卡片上一个按钮，从这条待办起一个日程草稿（默认在它的截止钟点前一小时，没有钟点就放今天第一个空档），在日历上打开编辑，你存了才写进 Google。这和「排一下今天」（§3.1c）用的是同一个动作。

**拖动（把一条待办拖到另一天）放到以后。** 拖动到底改的是截止日还是「打算哪天做」，不好一眼看出来，第一版先用卡片上的按钮改。

## 5. 开关【默认】

日历页右上角选日历的菜单里，多一项「待办」，和每个日历一样可以关。关了就是现在的样子。记在这台设备上，和隐藏日历记的地方一样。默认开。

## 6. 不做的

- 不把待办写进 Google 日历，也不建一个「Zirma 待办」日历。待办是你的数据，留在主节点。
- 不给待办加「要多久」。时间格里只画截止线，不画块。要块，就「放进日历」或「排一下今天」。
- 不在过去的日子里画拖下来的影子（§2）。
