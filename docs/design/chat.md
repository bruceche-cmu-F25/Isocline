# 对话页：和 Zirma 的对话也是一个模块

> 状态：v0.2（2026-11-27）**已批准**：第 7 节五条都按建议定了（Bruce：「Approve」）。代码没开始，按第 5 节 C1 → C3 做。v0.1 同日草案。Bruce：「可以加一个 chat 的 module，里面可以展开我们的 conversation」。
> 原型：`prototype/chat.html`（中英文；深浅色；手机宽度；「现在 / 提议」两种对照）。
> 依据：`docs/design/workspace-architecture.md` §6「页面自己的侧栏」（模块那一组都有自己的侧栏）；本仓库的 `packages/ui/src/shell/Nav.tsx`（现在的对话列表）、`App.tsx`（`select`、`selectFromList`、Zirma 面板的三种状态）、`shell/ZirmaPanel.tsx`、`ArchivedConversations.tsx`；开发模式的「代码」页（`core.dev`，会话也是一页一个）。
> 标记：**【事实】** 读代码核实过；**【建议】** 本方案的提案（已批准）；第 7 节是定下来的五条。

## 0. 结论

1. **加一页「对话」，放在侧栏「模块」那一组。** 它和笔记、链接、邮件一样有自己的侧栏：「+ 新对话」，然后按时间分的对话列表，最下面「已归档」。页面就是选中的那段对话，占满整页。
2. **主侧栏里的对话列表拿掉。** 主侧栏只剩页面列表，和「模块都有自己的侧栏」那条规矩一致：对话在「对话」页里找。
3. **「Zirma 铺满整页」这个状态就是对话页。** 从对话页里（和 ⌘K 搜到的）打开的对话在页面里；从别处（通知、运行记录、底部那一行、自动化）打开的，照旧在页面旁边的 Zirma 面板里，你在看的那一页不动。
4. **⌘. 的面板和底部那一行都不变。** 在任何页面都能问 Zirma；问完，那段对话自然出现在对话页的列表里。
5. **不改数据，不改协议。** 只是界面换个地方放：对话、归档、改名、未读、等你的数字都是现成的。

## 1. 现在到哪了

【事实】

- **主侧栏（日常模式）**从上到下：「今天」、工作台那一组（通知、日历、待办）、模块那一组（邮件、链接、笔记、自动化），然后一个「对话」标题（带「已归档」菜单和「+」），下面是日常对话的列表。每行是状态点、标题、时间（有事等你时换成数字），行尾一个归档按钮；双击改名。开发会话不在这里，在「代码」页里按项目列。只给自动化跑的对话（`automationOnly`）不列。
- **点列表里的一段对话**（`selectFromList`）：Zirma 面板没开时，它铺满整页（`alfred: "wide"`）；面板已经开在页面旁边时，只在面板里换一段对话，页面不动。
- **Zirma 面板有三种状态**：关着、开在页面旁边、铺满整页。面板头上有一个按钮在「旁边」和「铺满」之间切换。
- **从别处打开对话**（`select`）：通知、运行记录、底部那一行、⌘K，都在页面旁边打开面板。
- **手机上**：侧栏是一张从左边拉出的单子，对话列表也在里面；右下角的圆形 Zirma 打开当前对话。
- **开发模式**已经是「一个会话一整页」：「代码」页，侧栏按项目列会话。

## 2. 从第一性原理出发

- **对话是一种要来回找的东西。** 你会回到上周问过的那件事，会同时开着几段。这正是「一页里有几个地方要来回走」，所以它该有自己的侧栏，和别的模块一样。
- **主侧栏现在做了两件事：去哪一页、去哪段对话。** 对话一多，列表把页面挤到上面一小截，也让模块一组和对话一组长得不一样。拆开以后，主侧栏只回答「去哪一页」。
- **「铺满整页」本来就是一页。** 它占了页面的位置，却不在页面列表里，后退、⌥数字键、⌘K 都找不到它。做成一页，它就和别的页一样能去、能回。
- **旁边的面板是另一件事：边看边问。** 你在看邮件时问 Zirma，答案应该在邮件旁边，而不是把你带走。这件事不动。

## 3. 通用语言

| 词 | 意思 | 不是 |
|---|---|---|
| 对话页（Chats） | 模块那一组里的一页，`core.chat`，有自己的侧栏 | 不是 Zirma 面板 |
| Zirma 面板 | 页面旁边那一栏，⌘. 开关，边看边问 | 不再有「铺满」那一种 |
| 当前对话 | 路由里的 `selected`；对话页和面板看的是同一段 | — |

## 4. 方案

### 4.1 对话页

```
┌ ‹ 对话 ─────────────┬──────────────────────────────────────────────┐
│ + 新对话            │  周五的设计评审                         ⋯    │
│                     │                                              │
│ 今天                │   你：帮我把周五评审要讲的三件事列出来        │
│ ● 周五的设计评审    │   Zirma：……                                  │
│   发票要不要报      │                                              │
│ 前 7 天             │                                              │
│   搬家清单       2  │                                              │
│   读那篇 RAG 的文章 │                                              │
│ 更早                │                                              │
│   …                 │  ┌──────────────────────────────────────┐    │
│                     │  │ 接着说……                       ⏎    │    │
│ 已归档  12          │  └──────────────────────────────────────┘    │
└─────────────────────┴──────────────────────────────────────────────┘
```

- **页键 `core.chat`**，图标 `chat`，名字「对话 / Chats」，在模块那一组，排在最后（邮件、链接、笔记、自动化、对话），能像别的页一样拖动排序、隐藏。
- **侧栏**（照 `side-tree.css`，和笔记、链接、邮件一个样子）：
  - 「‹ 对话」回到页面列表（壳里现成的）。
  - 「+ 新对话」一行，在最上面，和笔记的「+ 新页面」同一个位置。
  - 对话按最后更新的时间分三段，每段一个灰色小标签：「今天」「前 7 天」「更早」。没有的段不出。
  - 每行：状态点（在做事、等你、有新回复）、标题、等你的数字（没有就空着，时间不写，标签已经说了是哪段）。
  - 悬停时行尾出「⋯」：改名、归档。双击改名照旧。
  - 最下面一行「已归档」，点了打开现在那张已归档的单子（`ArchivedConversations`，弹出的，背景模糊），可以恢复。【C1 改：原来写的是页面换成列表并带个数；个数要多问一次主节点，单子本来就有，先用它。】
- **页面**：选中的那段对话，占满整页，宽度和现在「铺满」一样（正文有最大宽度，靠左偏一点，和笔记页一样的道理）。底下是输入框。顶上是标题和「⋯」（改名、归档）。
- **没选对话时**：页面上是一个空的新对话，输入框获得焦点。和现在点「+」一样。
- **对话页上不出 Zirma 面板。** 页面本身就是对话，旁边再开一栏是重复的（壳的 `bare` 页已经是这样）。⌘. 在这一页什么也不做。

### 4.2 主侧栏

- 去掉「对话」标题、它的「+」和「已归档」菜单、对话列表。
- 主侧栏剩下：「今天」、工作台一组、模块一组（现在多了「对话」）、底部的连接状态。
- 「对话」那一行显示等你的总数（各段对话 `attention` 的和），和别的页的数字一样。有新回复没看时，图标旁一个小点。

### 4.3 打开一段对话，会落在哪

| 从哪 | 落在哪 |
|---|---|
| 对话页的侧栏 | 对话页的页面里 |
| 对话页上点「+ 新对话」 | 对话页，一段新的 |
| 通知、运行记录、自动化的「看对话」 | 页面旁边的 Zirma 面板（不变） |
| 底部那一行、⌘J | 正在开的那段对话，在面板里（不变） |
| ⌘K 搜到一段对话 | 对话页 |
| 面板头上原来的「铺满」按钮 | 改成「在对话页打开」：跳到对话页，就是这一段 |

- 「当前对话」只有一个：面板和对话页看的是同一段。你在面板里问了一句，再点到对话页，看到的就是它。
- 去掉 `alfred: "wide"` 这种布局。存着它的设备，读到时当成「开在旁边」。

### 4.4 手机

- 手机没有侧栏，对话页照「链接」在窄屏上的做法：先是对话列表（同样分三段，顶上「+ 新对话」），点一段进去是整屏的对话，顶上「‹」回到列表。
- 左下的页面药丸里多一个「对话」。右下圆形的 Zirma 不变：点它是当前对话，按住是快说。
- 侧栏单子里不再有对话列表。

### 4.5 开发模式

- 不动。开发会话照旧在「代码」页里按项目列；对话页只列日常对话（没有 `projectId`、不是 `automationOnly` 的），和现在主侧栏列的一样。

## 5. 搭建顺序

每一刀都能单独用。

1. **C1 对话页**：页键 `core.chat`、侧栏（新对话、分三段、已归档）、页面里的对话（用面板里现成的对话组件）。主侧栏的列表先留着，两边都能用。【已做，2026-11-27】侧栏收起时列表放进页面左边；页面窄时先列表、点进去是对话（第 4.4 节手机上的样子，C3 只剩页面药丸和侧栏单子）。归档走和主侧栏同一个 `useArchive`。
2. **C2 收拢**：主侧栏去掉对话列表；`selectFromList` 改成去对话页；去掉 `wide`，面板头的按钮改成「在对话页打开」；⌘K 的对话结果去对话页；「对话」一行的数字。
3. **C3 手机**：对话页的一层层点进去；页面药丸里加「对话」；侧栏单子去掉列表。

每一刀：`npm test`、`npm run typecheck`，在浏览器里看中英文、窄屏、深浅色，e2e 覆盖「从哪打开落在哪」那张表。

## 6. 这一轮不做

- 不做对话的搜索框（⌘K 已经能搜到对话）。
- 不做对话的文件夹、标签、置顶。
- 不把开发会话并进来。
- 不改对话本身的样子（消息、回执、授权请求）。
