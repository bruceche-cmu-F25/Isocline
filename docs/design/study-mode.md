# 学习：第三种模式，一个课题一张书桌（草案）

> 状态：v0.1（2026-11-22），**草案，等你看**。方向你在对话里说了「可以」：第三种模式、一个课题一个文件夹、固定的五样、固定的三栏。细节都还没有逐条定，第 8 节是要你决定的。没有写任何代码。
> 原型：`prototype/study.html`（2026-11-22；搭课题、今天、全貌、读材料和划词、练习；中英文；深浅色）。
> 依据：pi-web-robin 的 Learning Hub、研究台、练题（`docs/learning-roadmap.md`、`docs/research-reading-room.md`、`docs/agents/learning-study.md`）；本仓库的 `docs/research/workspace-capabilities.md`、`docs/design/dev-mode.md`、`docs/design/notes.md`、`packages/server/src/profiles.ts`、`packages/core/src/files.ts`。
> 标记：**【事实】** 读代码或文档核实过；**【建议】** 本方案的提案；**【没核实】** 凭已有了解写的，动手前要查。没有标记的段落是【建议】。

## 0. 结论

1. **学习是 Alfred 的第三种模式：日常 | 开发 | 学习。** 开发模式是「一个代码文件夹，加上在里面干活的会话」。学习模式是「一个课题文件夹，加上一张固定的书桌，和一个知道你学到哪了的 Alfred」。
2. **单位叫课题。** 学一门课、读一批论文、弄懂一个概念、备战面试，都是开一个课题。不叫「工作台」，那个词在 Alfred 里已经指整个主窗口。
3. **每个课题固定有五样：目标、地图、材料、练习、笔记。** Alfred 不是第六样，它贯穿这五样。
4. **页面是固定的三栏：** 左边是地图，中间是台面（一次只开一样东西），右边是 Alfred。不同的课题变的是内容，不是版面。
5. **核心动作是划词：** 解释、举例、考我、记下。答案回到书桌上：「记下」进笔记，「考我」变成一道练习，过几天到期。
6. **搭课题只要一句话。** Alfred 直接给出目标、地图和头几份材料的草稿，你在草稿上改，不先回答一串问题。
7. **进度只认练习的记录。** 打开过、读过不算会了。你自己标的「我会」另算，画法不同。
8. **课题是一个 Markdown 文件夹**，默认放在笔记库里。内容归你，别的编辑器也能开。
9. **求职只有一半进来：** 备战面试、改简历是课题；扫职位、打分、投递、跟进是一条流水线，另做模块，不在这份文档里。

## 2. 从第一性原理出发

先不看页面，看一个人要学会一样东西，需要什么：

| 你要的 | 在课题里是 | 回答的问题 |
|---|---|---|
| 知道自己在学什么、为什么、学到什么算成 | **目标**：一页 | 我在学什么 |
| 看见全貌，知道自己在哪 | **地图**：这件事由哪几块组成，每一块我到哪了 | 全貌和我的位置 |
| 知道怎么学、用什么学 | **材料**：挂在地图的块上 | 用什么学 |
| 重复，直到真的会 | **练习**：到期会回来 | 我真的会了吗 |
| 留下我弄懂的东西 | **笔记**：用自己的话 | 我现在懂成什么样 |
| 卡住的时候有人问 | **Alfred**：知道上面五样，知道你开着哪一页 | 这里我不懂 |

由此推出四条原则：

- **骨架固定，内容自由。** 这是做给很多人用的。五样和三栏对每个课题都一样，所以学一次就会用；你能改的是地图上有什么、挂什么材料、怎么练。不做可以随便拼的仪表盘。
- **进来是接着学，不是看报表。** 每天回来的人要的是下一步，所以进课题先看到「今天这一步」。
- **问过的就是不懂的。** 你划过的词、问过的问题、答错的题，是练习最好的来源。Alfred 不凭空出题。
- **证据不是模型说的。** 开发模式里，改动看 git 差异，不看模型说「我改了」。这里一样：会没会，看练习记录，不看读没读过，也不看 Alfred 说「你掌握了」。

为什么是一种模式，不是日常那一边的一个页面：它和开发模式是同一个形状。

| 开发 | 学习 |
|---|---|
| 代码文件夹（项目） | 课题文件夹 |
| `AGENTS.md` | 目标那一页，Alfred 每一轮都读 |
| 文件树 | 地图 |
| 编辑器和差异 | 台面 |
| 测试 | 练习 |
| 权限模式 | Alfred 的态度（讲透、只给提示、一起规划） |

## 3. 通用语言

| 词 | 英文 | 含义 | 不是什么 |
|---|---|---|---|
| 学习（模式） | Study | 顶栏的第三个图标；侧栏和页面换成课题那一套 | 不是「学习」这个领域色（领域是日程和待办上的标签） |
| 课题 | Topic | 一件要学会、要弄清的事；一个文件夹 | 不是工作台（整个主窗口），不是开发项目 |
| 目标 | Goal | 课题的一页说明：学什么、为什么、算成的标准、期限、底子、节奏 | 不是待办 |
| 地图 | Map | 课题由哪几块组成；一个两层的大纲 | 不是关系图，不画节点连线 |
| 块 | Part | 地图上的一项；材料、练习、笔记都挂在块上 | 不是一节写好的课 |
| 材料 | Material | 用来学的东西：文件、链接、书的一章、Alfred 写的讲解 | 不是笔记（笔记是你的话） |
| 练习 | Practice | 一道要你作答的东西：问答卡、复述、题 | 不是阅读 |
| 作答 | Attempt | 你做了一次练习，和这次的结果（记得、模糊、忘了） | 不是打开过 |
| 台面 | Desk | 中间那一栏，一次只开一样 | 不是多个窗格 |
| 态度 | Stance | Alfred 在课题里的三种做法：讲、提示、规划 | 不是三个「人」，形象和名字始终是 Alfred |
| 做法 | Recipe | 搭课题时的四种起点：系统学习、研究、弄懂一件事、备战 | 不是四种页面 |

## 4. 方案

### 4.1 课题和它的文件夹

- 一个课题 = 笔记库里 `学习/` 下的一个文件夹（英文界面建的叫 `Study/`）。也可以像开发项目那样指向别处的一个文件夹。
- 文件夹里：

```text
Alfred Notes/学习/线性代数/
  目标.md          一页：学什么、为什么、算成、期限、底子、节奏
  地图.md          大纲：阶段、块；块下面的链接就是它的材料
  材料/            你放进来的文件（PDF、Markdown、图片）
  笔记/向量.md      每一块一篇，第一次「记下」时才建
  讲解/矩阵乘法.md   Alfred 写的讲解，开头标明是它写的和依据的出处
```

- **地图的格式是普通 Markdown**，在 Obsidian 里也读得通：

```markdown
## 矩阵
- 矩阵乘法 ^b4
  一句话：把一个变换接在另一个后面。
  - [线性代数的本质 · 第 4 集](https://…)
  - [[材料/第 3 章.pdf]]
- 行列式 ^b5
```

  `##` 是阶段，第一层列表是块，块后面的 `^b4` 是它不变的编号（Obsidian 的块引用写法），块下面的链接是材料。你改名字、挪顺序，编号不变，练习和笔记就不会掉。

- **什么在文件里，什么在数据库里：**
  - 文件（真相）：目标、地图和材料清单、笔记、讲解。数据库只有它们的索引，删了能重建。
  - 数据库（记录）：练习题、每一次作答、下次到期的时间、划词问过什么。它们是带时间的证据，像回执一样记在主节点，不放进文件；可以导出成一份 `练习.md`。

### 4.2 五样

**目标。** 一页，六行：学什么、为什么、学到什么算成（要能观察到，例如「能独立推出反向传播」）、期限、现在的底子、节奏（每周几次、一次多久）。Alfred 每一轮都读。你直接改；Alfred 要改走提议。

**地图。** 两层：阶段和块，一块一句话。Alfred 起草，你随便加、删、挪。每一块有一个状态，由证据推出来（4.6）。地图同时是导航：点一块，台面打开这一块。

**材料。** 四种：

| 种类 | 例子 | 能划词吗 |
|---|---|---|
| 文字 | Markdown、笔记、Alfred 的讲解、读得出文字的 PDF、提取过正文的网页 | 能 |
| 原样的外站 | 视频、嵌进来的课程页、题库 | 不能，在右边问 |
| 只是一个指向 | 「《线性代数应该这样学》第 3 章」（书在你手上） | 不能，读完回来练 |
| Alfred 写的讲解 | 一块没有合适材料时，它按固定的样子写一篇 | 能 |

Alfred 写的讲解照 Robin 的「教学契约」：一个引出动机的问题、三个讲清楚的概念、一个算到底的例子、一个常见误解和纠正、出处。它用 Alfred 色标出「Alfred 写的」，不冒充教材。

材料从三处来：你放进来、Alfred 找来（你点头才挂上）、Alfred 写。

**练习。** 第一版三种：

| 种类 | 怎么做 | 谁判 |
|---|---|---|
| 问答卡 | 看问题，先在心里或纸上答，再翻开答案 | 你自己点：记得、模糊、忘了 |
| 复述 | 「用自己的话把这一块讲一遍」，写下来 | Alfred 对照材料指出缺了什么，给一个建议的档；记下的是你点的那一档 |
| 题 | 一道要算、要写的题；提示一级一级给，最后才是答案 | 同上 |

- 来源：你在划词时点「考我」；一块读完时 Alfred 提议 3 到 5 张；你自己写；答错的会更早回来。
- 间隔【建议，第一版】：固定的阶梯 1、3、7、16、35 天。「记得」上一级，「模糊」留在原级，「忘了」回到 1 天。以后可以换成 FSRS 这类算法【没核实它的许可】。

**笔记。** 每一块一篇 Markdown，就是笔记库里的普通笔记。「记下」把划的那段话或 Alfred 的回答追加进去，带出处。你随时改；Alfred 改你写的走提议（同 `notes.md`）。

### 4.3 页面

用的是现成的壳，不加第四栏：

| 侧栏（学习模式下） | 页面 = 台面 | Alfred 面板 |
|---|---|---|
| 最上面：现在是哪个课题，点开换课题或新建 | 一次只开一样 | 这个课题的对话 |
| 「今天」「全貌」两行 | | 头上写着现在的态度：讲、提示、规划 |
| 地图：阶段和块，每块一个状态点 | | 可以收起，台面就更宽 |
| 最下面：练习（到期几张）、笔记、材料 | | 窗口窄时默认收起，问的时候打开 |

不在课题里时，侧栏是课题的列表，页面是「新课题」。

台面有六种视图：

1. **今天**（进课题的默认页）：Alfred 的一句话（上次到哪了），一个「接着学」的按钮，到期的练习（几张、大约几分钟），这一周的节奏（三次里的第二次）。短，不滚屏。
2. **全貌**：目标在上，整张地图在下，每一块带状态、材料数、练习数。这是「世界观」那一页，也是改地图的地方。
3. **一块**：这一块的一句话、它的材料、它的练习、它的笔记。从这里进去读或练。
4. **读**：一份文字材料占满台面。可以划词（4.4）。记住读到哪，下次接着读；这个位置不算进度。
5. **练**：一次一道。答的地方、提示阶梯、三档按钮。做完一组回到「今天」。
6. **规划**：目标那一页可改的样子，右边是规划态度的 Alfred。搭课题和每周回看都在这里。

手机：一次一栏。地图在抽屉里，台面是主栏，Alfred 从底栏的形象打开。切换时三栏都不卸载，写了一半的作答不会丢（Robin 的做法）。

版面按页面这一栏的宽度排（`@container page`），窄到 320px 中英文都不叠字。

### 4.4 划词

- 在能划词的材料里选中一个词或一句话，旁边出四个按钮：**解释、举例、考我、记下**。
- **解释、举例**：答案出在选中处旁边的一张小卡上，两到四句，按目标页里写的底子来讲。小卡上有：记下、考我、接着问。
  - 这一问是一次用完即弃的小任务：只带选中的话、它所在的那一段、目标页的底子那一行。它不进课题的长对话，否则几十个查词会把对话撑满。
  - 「接着问」才把这一问和答带进右边的对话。
- **考我**：Alfred 写一张问答卡，直接加进这一块的练习，页面上出一行「加了一张 · 撤销」。这是本地、可撤的改动，不走提议。
- **记下**：追加进这一块的笔记，带出处，同样可撤。
- 划过什么都记一笔（哪一块、哪份材料、哪句话）。一块读完时，Alfred 用它提议：「这一块你问过 4 处，做成卡片吗？」
- 手机上系统自己有选中菜单，所以四个按钮出在屏幕底部的一行，不出在选中处旁边。
- 小卡上不放输入框（风格文档：只有一个地方写字）。

### 4.5 Alfred 在课题里：三种态度

| 态度 | 什么时候 | 规矩 | 能动什么 |
|---|---|---|---|
| **讲** | 台面上开着材料、一块、全貌 | 讲透，按你的底子；引材料里的原话 | 读这个课题；加笔记、加练习（可撤）；改地图走提议 |
| **提示** | 台面上开着一道练习 | 不先给答案：先问你卡在哪，再一级一级提示；你说「给我答案」才给 | 读这道题和你的作答；记下作答。它没有能读出标准答案的工具 |
| **规划** | 搭课题、规划页、每周回看 | 先给草稿，不先提问；说清每个猜测 | 读目标、地图、作答的统计、日历上哪些时间有事；所有改动都是提议 |

- **态度跟着台面走**，不用你切。你可以盖过它（「直接告诉我答案」）。
- **三种态度是三条对话**，每个课题各一条。原因是 Robin 踩过的：教练和导师在同一条会话里会读到对方的指令。它们共用的是课题的状态（目标、地图、笔记、作答），不是聊天记录。
- 面板头上写「Alfred · 讲」。形象和名字不变。
- 每一轮 Alfred 都拿到：目标（有上限）、地图和每块的状态、你现在开着什么、选中了什么。这用的是已有的「在 X 页问的」，随任务交过去。

### 4.6 进度只认证据

一块的状态：

| 状态 | 画法 | 怎么来的 |
|---|---|---|
| 没开始 | 空心圈 | 没有任何记录 |
| 在学 | 半圈 | 读过、问过，或者练过但没全过 |
| 该复习 | 琥珀色的点，带「到期 n」 | 有到期的练习 |
| 会了 | 实心点 | 这一块的每道练习都答对过，而且现在没有到期的 |
| 你标的 | 空心圈里一个勾 | 你自己说「这块我会」；没有练习记录支持 |

- 一块没有练习，就到不了「会了」，只能是「你标的」。所以读完一块 Alfred 会提议做几张卡。
- 整个课题的进度 = 会了的块数 / 总块数，写成字（「9 块里会了 3 块」），不画大进度条。
- Alfred 的回复里不许说「你已经掌握了」，它只能引记录（「这三张你上周都答对了」）。

### 4.7 搭一个课题

1. **说一句话。** 例如「三个月内能读懂扩散模型的论文」。可以顺手拖进几份材料。
2. **Alfred 给草稿**，一张提议：
   - 它猜的做法（4.8），是一个能换的标签；
   - 目标页六行，猜的地方用虚线标出来（底子、节奏、期限）；
   - 地图第一版：2 到 4 个阶段，5 到 9 块；
   - 头两三份材料，带来源。
3. **你在草稿上改**：点着改，或者在底下说一句（「训练那部分我不需要」），草稿在原地变。
4. **点「开始」**：建文件夹和文件，打开第一块。「排进日历」是另一个可选的提议，因为要写日历。

不做向导，不做十个问题的问卷。猜错了改起来便宜；一上来就问，人会走。

之后**每周回看一次**（自动任务）：按这一周的作答，Alfred 提议改地图或节奏（「行列式三次都卡在同一处，前面加一块『线性无关』？」）。计划是活的。

### 4.8 四种做法

做法只决定草稿的样子，不决定页面：

| | 系统学习 | 研究 | 弄懂一件事 | 备战 |
|---|---|---|---|---|
| 例子 | 线性代数、日语 | 「扩散模型为什么比 GAN 稳」 | 「TLS 握手到底发生了什么」 | 面试、考试 |
| 地图 | 阶段和章节 | 问题和子问题 | 一个问题，三五个子问题 | 考点或面试轮次 |
| 材料 | 课、书 | 论文 | 网页、文档 | 题库、职位描述、你的简历 |
| 练习 | 问答卡、题 | 复述、对比两篇 | 给别人讲一遍 | 题、模拟问答 |
| 节奏 | 每周几次 | 随手 | 没有，一两次弄完 | 倒排到那一天 |
| 算成 | 能做出某样东西 | 一篇自己写的结论 | 一页说明 | 通过 |

「弄懂一件事」是最轻的：没有日历，没有每周回看，做完就归档。不是每个课题都要一个计划。

### 4.9 和日常那一边怎么接

- **今天页**：有到期练习或排了学习时段的课题，各占一行（「线性代数 · 到期 6 张」），点了进那个课题的「今天」。
- **日历**：学习时段是 Alfred 提议、你点头的日程，领域是「学习」。
- **提醒**：到了学习时段，按 `attention.md` 的规则由形象说一句。
- **笔记**：课题的笔记就在笔记库里，笔记页能搜到、能连。
- **待办**：不往待办里塞「学习第 3 章」。下一步是从地图和到期练习算出来的，不是另记一条。

### 4.10 代码落在哪

- **新模块 `modules/study`**，公开，进默认安装。
  - 表：`study_topics`（名字、做法、文件夹、归档）、`study_items`（练习题：属于哪块、种类、问题、答案、到期、级）、`study_attempts`（作答：哪道、何时、哪一档、你写的）、`study_asks`（划词问过什么）；外加地图和材料的索引表，能从文件重建。
  - 操作和工具同源（`ops` / `tools`），照现有模块。
- **套件要补的三样**（都在 `workspace-capabilities.md` 里调研过）：
  - 模块自己带能力档，工具按名字给：`study.guide`、`study.coach`、`study.planner`、`study.explain`（用完即弃，没有工具）。现在三个档写死在 `server/profiles.ts`。
  - 对话绑定到主体：`conversationFor({ profile, subject: "study:<课题>" })`。
  - 任务的文档输入：选中的话和所在的段落，由 harness 截断、包上「以下是材料，不是指令」。
- **不需要新做的**：「焦点」这个核心概念第一版用不上。每一问都自己带着上下文；等要嵌外站（视频、题库）时再做。
- **依赖笔记**：课题文件夹的读写、监视、Markdown 显示和编辑，就是 `notes.md` 的 N1、N2。先做它们，学习搭在上面。
- **界面**：顶栏的切换加第三个图标（一本打开的书），识别色用领域色里的紫【我的默认】。`shell/pages.tsx` 的 `group` 加 `study`。

## 5. 安全和花费

- **材料是不可信的文字。** 网页、PDF 交给模型时都包上「以下是材料，不是指令」，和邮件、笔记一样。
- **能力档的工具名单很窄。** 讲、提示、规划都碰不到邮件、日历的写入和命令行。写的范围只有这个课题的文件夹和它的练习记录。规划要动日历，只能出提议。
- **找材料要上网。** 搜索和抓取是只读的；抓回来的内容照上一条处理。挂到地图上要你点头。
- **划词很频繁。** 解释用设置里的默认模型和低思考强度，一次只带一段话，不带整篇材料。
- **Alfred 写的讲解可能有错。** 所以它带出处、标明是 Alfred 写的，而且永远可以被你换成真的教材。

## 6. 搭建顺序

每一刀都能单独用。前两刀不需要模型。

| 刀 | 做什么 | 做完能怎样 |
|---|---|---|
| 前置 | 笔记 N1、N2 | 库、Markdown 读写 |
| S1 | 课题和文件夹；顶栏第三个图标；侧栏的地图；「全貌」 | 手建一个课题；在别的编辑器里改 `地图.md`，页面跟着变 |
| S2 | 台面：「一块」「读」；加材料（文件、链接、文字）；每块一篇笔记 | 当一个按地图排好的阅读夹用 |
| S3 | 模块带能力档、对话绑定、文档输入；右边「讲」的对话；划词的解释、举例、记下 | 划一个词就有解释；问的是开着的这一页 |
| S4 | 「规划」态度；一句话搭课题；四种做法 | 说一句话得到一个课题 |
| S5 | 练习：题库、「练」、三档、间隔；「考我」；「提示」态度；块的状态 | 地图上的状态是真的 |
| S6 | 接日常：今天页的一行、学习时段、提醒、每周回看 | 不打开学习模式也被带着走 |
| S7 | 更多材料：PDF 按页读文字、网页正文（和 Links 的第二步一起）、嵌外站和视频 | 读论文、跟外站的课 |

## 7. 这一轮不做

- 求职的流水线（扫职位、打分、投递、跟进）。
- 关系图、节点连线的知识图谱。
- 自动判分的编程题、在页面里跑代码。
- 语音的模拟面试（等全双工语音）。
- 播客、周报、视频清单这类「订阅来的东西」：它们不是课题。
- 多人、排行、打卡连胜。
- 分享课题。文件夹天然能给别人（不带你的作答），以后可以做成一件正式的事。
- 可以随便拼的版面。
