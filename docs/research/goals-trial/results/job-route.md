# 路线：一年内换一份后端工程师的工作

## 别人一般是怎么走到的

我找到三种走法。它们的区别在于先做什么、靠什么推动自己往前走。

### 先定岗位，再按简历和岗位描述收窄复习
**这条路是什么样** 先拿几份想投的岗位描述，看哪些技能反复出现，再和自己的简历对照，缺什么补什么。复习的顺序是先项目和简历，再 Java、数据库、Redis，然后 Spring 和系统设计，算法每天穿插。每周找人模拟面一次，从简历开始问。[1]
**代价** 它默认你已经学过主要知识。资料自己说，第一次系统学 Java 后端的人，8 周也只是起点。[1] 复习范围跟着简历和岗位走，所以换一类岗位，要准备的内容要重新算。
**靠什么** JavaGuide 的面试通关计划，里面有 4 周和 8 周两个版本。[1]
**大约多久** 猜测：已有基础的话 1 到 2 个月；基础薄的话，前面要先加几个月补课。

### 从零按路线系统学，再做项目
**这条路是什么样** 按一张完整的学习路线，从语言基础开始，依次学数据库、框架、工具，然后是并发、JVM、分布式等进阶内容。路线作者的建议是：零基础时先跟视频一步步走，不要一上来就做项目，否则容易学得杂乱。[2] 路线里也分了层：只想找小厂工作，重点放在基础、数据库、框架和工具；想进大厂，再加 JVM、分布式、高并发等。[2]
**代价** 内容很多，路线自己也承认容易被劝退。[2] 学了的东西有不少在工作中用不到，只是面试要考。[2] 周期长，中间没有面试反馈，不知道自己学得够不够。
**靠什么** JavaGuide 的 Java 后端学习路线，它推荐的视频和书都列在里面。[2] 另一个选择是 roadmap.sh 的后端路线图。我只看到了搜索摘要，说它是社区做的、不限语言的技能地图。[3]
**大约多久** 猜测：半年以上到一年。

### 边工作边投、拿面经倒推着学
**这条路是什么样** 有一位测试开发转后端的人，在职期间没有时间通读大部头。他先把算法题过一遍，把旧项目重新总结，然后先投小厂找面试的感觉。之后哪块被问倒，就去看面经和多篇文章，补那一块。两三个月里面了十几家。[4]
**代价** 很累：他每天下班后学到凌晨两三点，还要抽时间面试。[4] 他还发现，转行的人在社招里仍被重点考基础，他的操作系统和网络很欠缺。[4] 这是 2020 年的个人经历，市场现在可能不同。
**靠什么** 牛客网上的这篇复盘，以及牛客上的各家公司面经。[4]
**大约多久** 他自己的经历是 2 到 3 个月的集中冲刺。[4] 那时他已经有过后端实习经历，你的情况不一定一样。

## 眼前这一段（以第一种走法为例）

### 第 1 步：收几份岗位描述，对一遍简历
**做什么** 找 5 到 10 份你真想投的后端岗位描述，把反复出现的技能记下来。再拿你现在的简历逐项核对，写出"岗位要、我没有"和"我写了、但答不上"的两张清单。
**为什么走这一步** 复习范围主要来自岗位要求和简历内容这两处。[1] 先定范围，后面才不会看到什么学什么。
**用什么走**
- JavaGuide 面试通关计划里的"第 0 阶段"：说明这一步留下哪几份材料。https://javaguide.cn/interview-preparation/backend-interview-plan.html

### 第 2 步：给每个项目写一张底稿
**做什么** 对每个重点项目写下业务背景、你负责的部分、一次请求怎么走、一个技术选择和一个遇到过的问题。再各准备 30 秒和 3 分钟的讲法。如果没有工作项目，课程项目或二次开发的开源项目也行，重点写你自己改了什么。
**为什么走这一步** 面试官通常从项目问起。项目讲不清，背再多原理也接不回自己的经历。数字要有来源，不要编。[1]
**用什么走**
- 同一份计划的"第一阶段"：里面有项目底稿的表格和自测的四个问题。https://javaguide.cn/interview-preparation/backend-interview-plan.html

### 第 3 步：对 Java、MySQL、Redis 抽题，看哪里只会说定义
**做什么** 三类各抽几道题，不看资料口头回答。只能说出定义的那一块，就是要补的地方。已经能结合项目讲的，不用再读一遍。
**为什么走这一步** 这三块覆盖面大，平均用力会浪费时间。先抽题再补，范围会缩小。[1]
**用什么走**
- 同一份计划的"第二阶段"：列出每块对应的面试题文章。https://javaguide.cn/interview-preparation/backend-interview-plan.html
- JavaGuide 学习路线：想从原理补起时，可看里面推荐的视频和书。https://javaguide.cn/roadmap/java-roadmap.html

### 第 4 步：每天留一小段做算法题
**做什么** 每天做一两道，先从二分、双指针这类常见题型开始，错题留着。
**为什么走这一步** 有笔试或代码面的岗位，算法要从头持续练，不要留到最后突击。第 1 步的岗位描述会告诉你要不要考。[1]
**用什么走**
- 同一份计划的"第四阶段"：列出算法题的主要类型。https://javaguide.cn/interview-preparation/backend-interview-plan.html

## 后面的段
- Spring、系统设计与场景题。
- 计算机网络、操作系统。
- 分布式、JVM 与线上排查，按简历和岗位取舍。
- 每周模拟面试，开始投递，每场后复盘。
