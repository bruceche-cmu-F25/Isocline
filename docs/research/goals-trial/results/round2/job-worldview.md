# 世界观：一年内换一份后端工程师的工作

## 整件事
**是什么** 换工作，就是让一家公司的面试官相信：你能把后端这摊事做好。后端是用户看不见的那一半程序。它管数据存哪里、请求怎么处理、系统出问题时怎么不垮。你要先让对方看到你做过什么（简历和项目），再让对方当面验证（几轮面试）。

**为什么** 公司没法直接看你的脑子，只能靠简历和几轮问答来判断。所以这件事的核心是：把你会的东西摆成别人能验证的样子。资料很多，但面试官真正在意的范围其实有限。国内的指南说，考察重心已从"知道"移到"能被追问到第三层"[1][3]。英文指南说，大致是写代码、接口设计、数据存储、分布式设计这四块[2]。

## 面试看什么：整条流程
这一部分讲面试从头到尾长什么样，以及各环节在查什么。

### 面试的几道关
**是什么** 流程大致是：招聘方先电话聊一下，再做一次技术初筛，然后是几轮正式面试，包括写代码、系统设计，有的还有接口设计和谈过往经历[2]。国内常见的是笔试加三轮技术面再加 HR 面，一份复盘里就是这样走的[4]。这像过几道关卡的闯关游戏，每关查的东西不同。

**为什么** 公司要用有限的时间，从不同角度确认同一件事：这个人靠不靠谱。各家轮数和顺序不同，有的公司用贴近真实工作的小任务代替算法题[2]。

### 同样的题，不同的要求
**是什么** 同一道题，对新人和对资深的人，评分标准不一样。英文指南说，新人看"做对没有"，资深的人看"取舍和出错时怎么办"[2]。这像驾校考试和赛车考核：都叫开车，及格线差得远。

**为什么** 你换工作时的年限和经验，决定了你被按哪一档来评。系统设计题对新人可能不考或只考轻量版[2]。

## 要会的东西：技术内容
这一部分讲面试里反复出现的几块知识，以及它们为什么总被问。

### 语言和基础
**是什么** 国内资料以 Java 为主线：语言本身、集合、并发（多件事同时做时怎么不打架）。再往下是计算机网络、操作系统和算法题[1]。这是盖房子的地基，看不见，但上面每一层都靠它。

**为什么** 有笔试或手写代码环节的岗位，算法会直接决定能不能进下一轮[1][2]。别的语言（Go 等）也出现在国内资料里，但我读到的详细资料基本都围绕 Java[3]。

### 数据库和缓存
**是什么** 数据库是存数据的仓库，常见的是 MySQL。缓存（如 Redis）是放在门口的小货架，常用的东西先从那里拿，不必每次进仓库。面试会问索引、事务和缓存失效时怎么办[1][2]。

**为什么** 英文指南称数据库深度是最常见的短板[2]。国内资料也把 MySQL 和 Redis 当作必问项，还要求能联系到你做过的项目[1]。

### 系统设计和稳定性
**是什么** 系统设计是回答"用户暴增、某个部件坏了，整套东西怎么撑住"。这像设计一座城市的交通：先有主路，再加红绿灯、分流和应急预案。内容包括消息队列、限流、重试、分布式锁等[1][2]。

**为什么** 两边的资料都说，光画出组件不够，还要说清出故障时会怎样[1][2]。是否需要深入，要看你的简历和岗位写了什么。单体应用、岗位也没要求分布式时，常见问题掌握即可[1]。

## 你的材料：简历与项目
这一部分讲你拿什么让别人相信你。

### 项目是面试的入口
**是什么** 面试官通常从简历和项目开始问，再顺着里面写到的技术一路追问[1]。项目像一份作品集：别人翻开一页，就会指着问"这里为什么这么做"。没有工作项目时，课程项目、改过的开源项目也能写，重点是你自己动过什么[1]。

**为什么** 项目讲不清，背再多知识点也接不上你的经历[1]。数字要有来源，不能编造[1]。这一点我只在一份资料里看到。

### 简历决定被问什么
**是什么** 简历上写了什么技术，面试官就可能问什么。岗位描述里反复出现的要求，也是准备的依据[1]。简历像菜单，客人会从上面点菜。

**为什么** 这让准备范围有了边界：它来自岗位要求和你简历上写的内容，不是整个后端领域[1]。

## 时间和节奏：一年这个框
这一部分讲"一年"在这件事里是什么位置。

### 准备期与投递期
**是什么** 现有的备考计划都比一年短得多：国内有 4 周和 8 周两个版本[1]，英文指南说，在职工程师每周约十小时、六周够用[2]。投递和面试本身，常常也要三到六周[2]。一年因此更像一条跑道：准备、投递、面试、等结果，都在里面。

**为什么** 这些计划都假设你已学过主要知识。第一次系统学的人，8 周也只是起点[1]。一年的好处是，不必把所有事挤在同一段时间里。

### 国内秋招春招的时间点
**是什么** 国内资料常提到"金三银四"，就是春季招聘旺季[5]。这像农历里的农忙时节：同样的力气，在不同月份收成不同。

**为什么** 这条我只见到搜索摘要，没有读到正文，也没查到别的来源，只能当作线索。
